## 🎯 Конечный Результат

### Требования к Функционированию

#### 1. **Подключения**

| Сценарий | Поведение |
|----------|-----------|
| **При запуске** | Однократное подключение ко ВСЕМ известным пирам (bootstrap + contact + discovered) |
| **Переподключение** | Только для bootstrap/contact, максимум 5 попыток, интервал 30 секунд |
| **Ручное подключение** | По запросу пользователя (через UI) |
| **DHT Discovery** | **Раз в 5 минут** (не 30 секунд!) |
| **mDNS Discovery** | Только в локальной сети (опционально) |
| **Лимит подключений** | **Максимум 50 одновременных подключений** |

#### 2. **Обмен Профилями**

| Сценарий | Поведение |
|----------|-----------|
| **При подключении** | Обмен **минимальными** профилями (без avatar/pinned) |
| **Полный профиль** | Только по запросу (кнопка "Обновить профиль") |
| **Аватарка** | Загружается отдельно по хешу (не в профиле) |
| **Pinned UUIDs** | **НЕ загружаются** автоматически |

#### 3. **Загрузка Элементов**

| Сценарий | Поведение |
|----------|-----------|
| **При обмене профилями** | ❌ **НЕ загружать** pinned элементы |
| **При открытии чата** | ✅ Загружать pinned элементы автоматически |
| **По запросу пользователя** | ✅ Загружать по кнопке "Загрузить элементы" |
| **Массовый обмен** | ❌ Не реализовывать (пока рано) |

#### 4. **Защита от Избыточного Трафика**

| Механизм | Описание |
|----------|----------|
| **Минимальный профиль** | ~200 байт вместо 50-500 КБ |
| **Отложенная загрузка** | Pinned элементы только при открытии чата |
| **Проверка в БД** | Не загружать существующие элементы |
| **Таймауты** | 60 секунд на загрузку элемента |
| **Одна попытка** | Не повторять неудачные загрузки |
| **Лимит подключений** | 50 одновременных подключений |

#### 5. **Лимиты Ресурсов**

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **Лимит адресов в БД** | ❌ **Не ограничен** | Хранить все адреса (включая мёртвые) |
| **Лимит подключений** | ✅ **50 пиров** | Ограничение потребления ресурсов |
| **Лимит DHT находок** | ✅ **100 пиров** | За одну сессию discovery |

            break
        }
